# Python Mini Projects

A collection of small Python projects built to practice programming, GUI development, automation, and problem-solving.

## Projects

* **Typing Speed Test** – GUI-based application to test typing speed and accuracy.
* **Snake Game** – Classic Snake game developed using Python.
* **Snake Water Gun Game** – A simple command-line game based on the classic Rock Paper Scissors concept.
* **Water Reminder** – Desktop reminder application that reminds users to drink water at regular intervals.
* **Quiz Taker** – Interactive quiz application that presents questions and tracks the user's score.

## Technologies

* Python
* Tkinter / GUI
* Python Standard Libraries

## Purpose

These projects were created as practice projects to strengthen Python fundamentals and explore different applications of Python, including games, GUI applications, automation, and interactive programs.
